扁平几何风 · 美团员工形象

纯色块零渐变，简洁几何形状构建角色，类似 Duolingo 的现代扁平设计风格

设计技法

  • 纯色块（zero gradients）：所有元素使用纯色填充，无渐变、无纹理
  • 几何形状：圆形头部 + 圆角矩形躯干 + 简单线条四肢
  • 微阴影浮起：统一 0 4px 0 rgba(0,0,0,0.08) 阴影营造轻微立体感
  • 美团品牌元素：黄色头盔 + 袋鼠耳凸起 + 深色制服 + 工牌
  • 4 种状态动画：空闲浮动 / 通话中脉冲 / 警报抖动 / 成功弹跳
